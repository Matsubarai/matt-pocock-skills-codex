# Matt Pocock Skills for Codex

An unofficial Codex plugin containing the **27 formal skills** from [mattpocock/skills](https://github.com/mattpocock/skills), with minimal adaptations for Codex. Upstream `in-progress` and miscellaneous skills are excluded.

## Skills and documentation

Browse the [skills](skills/) or see the [upstream README](UPSTREAM-README.md) for descriptions and workflows. The [upstream changelog](UPSTREAM-CHANGELOG.md) records changes to the original project.

Skills retain their upstream structure and workflows, with necessary adjustments to instructions, configuration, and directory layout for Codex. Original documentation is preserved and may describe Claude Code behavior.

The upstream snapshot and adaptation details are recorded in [PROVENANCE.json](PROVENANCE.json). See the [content diff](audit/CONTENT-DIFF.patch) for changes against that snapshot and the [directory map](audit/DIRECTORY-MAP.json) for file relocations.
